# 零硬編碼與機密保護原則 (No Hardcoded Secrets Rule)

- Agent 在編寫、重構或修復任何程式碼、組態檔或測試腳本時，**嚴禁硬編碼 (Hardcode) 任何敏感資安憑證**：
  1. 嚴禁將資料庫密碼、DSN 密碼、SMTP 登入密碼寫入程式碼或檔案中。
  2. 嚴禁將代理伺服器 (Proxy) 認證帳密、API 金鑰或 JWT 密鑰明文寫入程式碼。
- **環境變數載入與範例同步**：
  1. 所有敏感憑證一律必須優先自環境變數（如 `.env`）動態載入。
  2. 若程式碼中引入了新的環境變數需求，**必須同步更新 `.env.example`**，並附上清晰註解與安全的範例格式。
